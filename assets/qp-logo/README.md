# qp logo studies

Pixel art for a `qp` mark, drawn in [pixelsrc](https://github.com/scbrown/pixelsrc).
`q` and `p` flipped top to bottom are `d` and `b`, so the shadow the command
casts reads `db`. The gold or cream bands on the descenders are counting knots:
two on `q`, one on `p`.

None of these is wired into the README, the book or the UI.

## Sources

Each `.pxl` file is generated by the script beside it. The scripts draw a bitmap
and run-length encode it into pixelsrc `rect` unions, and their output is
byte-stable from run to run. Edit the script, not the `.pxl`.

| Source | Script | Contents |
|---|---|---|
| `qp-logo.pxl` | `gen.py` | Thread Workshop palette: `qp-mirror`, `qp-cast`, `qp-cast-light`, `qp-mark` |
| `qp-super.pxl` | `gen2.py` | Bright flat fields: `qp-sunset`, `qp-echo`, `qp-sun`, `qp-lines` |
| `qp-sun.pxl` | `gen3.py` | Three-line lettering, a corner sun and a slanted shadow, in eight colourways, plus the grid and the animation |

`qp-sun.pxl` holds the preferred set: the four violet and blue colourways
(`qp-sky-on-violet`, `qp-violet-on-sky`, `qp-violet-on-pale`,
`qp-sky-on-violet-cut`), the 2×2 compositions `qp-quad-0` to `qp-quad-3`, and
the animation `qp-cycle`, which steps one mark through the four colourways.

## Rebuild

Run from this directory with `pxl` 0.3.1. `gen3.py` imports `gen2.py`.

```sh
python3 gen.py && python3 gen2.py && python3 gen3.py
pxl validate --strict qp-sun.pxl
pxl render --strict qp-sun.pxl --sprite qp-sky-on-violet --scale 8 -o renders/qp-sky-on-violet.png
pxl render --strict qp-sun.pxl -c qp-quad-0 --scale 4 -o renders/qp-quad-0.png
pxl render --strict qp-sun.pxl --gif --animation qp-cycle --scale 8 -o renders/qp-cycle.gif
```

`renders/` holds every sprite at scale 8 (512 px), the four grid compositions at
scale 4 and `qp-cycle.gif`. `renders/qp-quad-spin.gif` is the four grid renders
joined into one GIF with Pillow, 700 ms a frame; pixelsrc does not animate
compositions.
