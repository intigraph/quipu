# First-use pack pointers

The same graph-use request is refused by the installed CLI before this change,
then fetches and composes a pinned archive with the candidate. Watch the query
find one target row and a fresh receiver reuse the verified archive offline.
The browser portion runs the actual explorer wasm in visible Chromium, through
the packaged runtime export: declaration does no loading, revoked trust refuses,
ROOT stays empty, offline cache reuse succeeds, and corrupt cached bytes refuse.
